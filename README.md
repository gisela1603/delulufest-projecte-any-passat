# Delulu_projecte-any-passat
Pàgina web d'un esdeveniment fictici, en aquest cas un festival musical anomenat DeluluFest creada a partir de fitxers html, css i javascript.

Per poder executar la web localment (en un servidor de desenvolupament) s'han d'utilitzar dues ordres que s'han d'escriure a la terminal: 

- npm install --global http-server (en cas de no estar ja instal·lat)
   
- http-server (per "crear" el servidor local)
   
Enllaç per accedir a la pàgina: projecte-any-passat.firebaseapp.com
